# OpenAgent Core

OpenAgent Core is an open-source, modular Agentic AI framework for building
goal-driven autonomous agents that can run locally or in the cloud.

This project focuses on **clarity, control, and extensibility** over magic.

---

## Why OpenAgent?

Most agent frameworks are:
- Hard to debug
- Over-abstracted
- Unsafe by default

OpenAgent is built to be:
- Explicit (you see every decision)
- Modular (swap planners, tools, LLMs)
- Production-oriented (limits, logging, config)

---

## Core Concepts

- **Agent Loop**: Plan → Act → Observe → Reflect
- **Role-based Agents**: Planner, Executor, Critic
- **Tool Registry**: Explicit tool permissions
- **Memory Layers**: Short-term, long-term, vector
- **LLM Abstraction**: Local or cloud
